# Shutdown regression source provenance

These are the exact original v6 private test sources, preparation inventory,
and research decision preceding the portable test lookup adaptation. Their
SHA-256 identities are recorded in `manifest.json`. They are Apache-2.0 project
source under the root LICENSE/NOTICE. The decision note retains primary sources
and distinguishes design guidance from copied implementation.

The executable tests live in `examples/validation/windows_handoff/`. Only their
source-verification lookups differ. Every request, quality, correction, terminal
fault, late scheduler uncertainty, cleanup, and primary-error preservation
regression remains unchanged. The original files here are historical source,
not standalone entry points; they expect private sibling directories.

The portable tests use the existing `shutdown-predecessor` archive for the exact
v5 harness/core/tests, and `arithmetic-feedback-predecessor` for the unchanged
19 executable helper/test/pin files. The original complete inventory remains
unaltered metadata, including identities of excluded private configs and
preparation-only files. No private config, result, environment, model, log,
personal path, or native binary is included here.

The harness itself is the exact reviewed v6 source, without a portability edit.
CPU fixture success does not establish real-model or installed-agent acceptance.
Failed earlier runs retain their original status; no result is exported here.
