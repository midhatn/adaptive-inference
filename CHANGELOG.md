# Changelog

## 0.2.0 — source preservation and durable task continuation

- Preserve native integration baselines and their pinned native dependency locally, with checksummed source reconstruction that needs no upstream fetch.
- Keep the complete source distribution usable as the project archive, including integration inputs, source references, licenses, tests and reproduction instructions.
- Add bounded SQLite task checkpoints and a resumable feedback runner. Preserve original intent and accepted progress across process termination; require reconciliation of interrupted effects instead of automatic replay.
- Add a reproducible process-death/restart demonstration, including a refused competing owner, corrective feedback and a single interrupted delivery that is not replayed.
- Add optional sustained-headroom admission and explicit context planning without reducing the caller's output allowance.
- Make the always-on agent goal, current contracts, preservation rules and development plan explicit. Keep source credit beside actual reuse.

The durable foundation passed 95 software tests on Windows, Linux and macOS with Python 3.11 and 3.12. Source preservation adds 15 checks and a complete offline restoration of 25,177 resulting files, including the overlays. Exact source-preservation validation is recorded in the evidence ledger. Process tests use deterministic callbacks. This release does not claim automatic startup of installed agents, physical power-loss certification, complete machine-wide resource handoff or native qualification of all engine profiles.

## 0.1.0 — portable gateway foundation

The initial release introduced the OpenAI-compatible gateway, bounded normal/background queue, execution-time feedback, acceptance/correction helper, eight engine profiles, ten client recipes and source overlays for earlier Strata/Hermes work. Validation included 45 software tests, four reconstruction checks, a fresh wheel installation and eight serial real-model arithmetic requests on one Strata composition. See the evidence ledger for the exact source, retained failure and scope.
